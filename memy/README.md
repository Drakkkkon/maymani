# Мое_мемы

Сайт для поиска, редактирования и сохранения мемов. Версия **0.1.0 альфа**.

Сайт: https://drakkkkon.github.io/Moe_memy/

- **Мемы** — вкладки «Новые» (100 свежих шаблонов), «Классика» (100 классических), «Избранное» (♥ шаблоны и сохранённые мемы), поиск.
- **Редактор** — блоки текста (шрифт, размер, цвет, обводка, плашка, поворот), обрезка картинки, размер холста (по умолчанию 1:1, 1800×1800).
- **Сохранение** — в базу сайта (IndexedDB в браузере) и JPEG на телефон.

Шаблоны: каталог imgflip (data/catalog.json, обновлён 20.11.2026).
