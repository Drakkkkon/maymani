Мое_город — новые 3D-модели дома 2×2 (заготовка версии 1.7.0)
================================================================
Что внутри
- models3d.js — файл моделей игры (js/models3d.js): к прежним dorm, balc, chim, port добавлены
    win   — обычное парижское окно (156 треугольников, текстура 15 КБ)
    winN  — парадное французское окно с фронтоном (182 тр.)
    arch  — арочное окно цоколя с рустом, замковым камнем и решёткой (390 тр., прозрачные углы через маску)
    cornice — карниз с кронштейнами и зубчиками (32 тр.)
- game_js_1.5.0_to_models.patch — правки js/game.js (применяются командой patch -p2 к game.js версий 1.5.0/1.6.0):
    стили стен euroP / brickP / arcadeP (штукатурка, кирпич и руст без нарисованных окон и арок),
    Shapes.part(..., xs) — растяжение модели по ширине, partMat — маска прозрачности,
    wins3 / arch3 / cornice3 — расстановка моделей на доме 2×2 эпохи «Бель-эпок».
    Работает только при «высоком» качестве графики; при среднем и лёгком дом выглядит как в 1.5.0/1.6.0.
- tools/ — мои инструменты: bake_part.py (GLB с сайта Hunyuan3D -> лёгкая модель + текстура), add_model.py (вшить модель в models3d.js),
    shot.py (снимок дома в настоящей игре через headless Chrome), tris.py (подсчёт треугольников).

Стоимость: дом 2×2 при высоком качестве ≈ 24.8 тыс. треугольников (было ≈ 8.9 тыс.), файл моделей 0.94 -> 1.17 МБ.

Чтобы выпустить 1.7.0: взять исходники 1.6.0 (Moe_gorod_v1.6.0.zip), положить models3d.js в gorod/js/, применить патч к gorod/js/game.js,
поднять версию (data.js, index.html ?v=, package.json), дописать «Что нового» и гайд, собрать node scripts/build.js, выложить на GitHub.
