МайМани — архив версий и журнал изменений (v1.2: Money 4.8.1 + iLife 1.1.0)
===========================================================================

Что нового в хабе 1.2
  • Новая страница ilife.html — приложение iLife: последняя версия, архивы iLife_v1.0.0.zip и
    iLife_v1.1.0.zip, журнал обновлений со скриншотами, ссылки на папку «iLife_архивы» и файлы на
    Google Диске, краткая инструкция по установке. На главной странице есть раздел «Другие приложения»
    и кнопка-чип «iLife 1.1.0 →».
  • Шесть Android-архивов с ключом подписи (.jks) и паролем убраны из папки archives/, чтобы их нельзя
    было случайно выложить на GitHub. В журнале они описаны по-прежнему, у них стоит пометка
    «не выложен». Сами файлы лежат в отдельном архиве MayMani_PRIVATE_Android_keys.zip —
    храните его только у себя (на Диске, не в репозитории).

Как открыть на ПК
  1. Распакуйте архив целиком (не запускайте из окна архиватора).
  2. Откройте index.html двойным щелчком в Chrome / Edge / Firefox.
  Интернет не нужен: страницы, архивы и скриншоты лежат рядом (без сети вместо Google Sans Flex
  подставится системный шрифт).

Как выложить на GitHub Pages
  1. github.com → New repository → имя, например, maymani → Public (для бесплатных Pages репозиторий
     должен быть публичным) → Create.
  2. «uploading an existing file» → перетащите СОДЕРЖИМОЕ папки MayMani_Hub_v1.2 (index.html должен быть
     в КОРНЕ репозитория, а не внутри вложенной папки). Веб-интерфейс GitHub принимает не больше
     100 файлов за раз, а в хабе их 98 вместе со скрытыми — надёжнее грузить частями: сначала index.html,
     ilife.html, README.txt, .nojekyll, .gitignore и папку shots, потом папку archives (каждый раз
     «Commit changes»). Либо используйте GitHub Desktop — там ограничения нет.
  3. Settings → Pages → Source: Deploy from a branch, Branch: main, / (root) → Save.
     Через 1–3 минуты хаб откроется по адресу https://ВАШ-ЛОГИН.github.io/maymani/.
  Файл .nojekyll должен лежать в корне (пустой, без расширения) — без него GitHub может «потерять»
  некоторые файлы.

Что внутри
  index.html  — страница «МайМани»: Money (сайт 3.0.0–4.8.1, ранние сборки, прототипы), раздел
                «Другие приложения», журнал (53 записи, поиск, скриншоты).
  ilife.html  — страница iLife: архивы, журнал, файлы на Google Диске, установка.
  archives/   — 31 архив: 29 архивов Money и 2 архива iLife. Кнопка «Скачать» рядом с каждым.
  shots/      — 62 скриншота, на которые ссылаются журналы.
  .nojekyll, .gitignore — служебные файлы для GitHub.

Важно
  • Репозиторий публичный — значит, всё его содержимое видно всем. В журнале Money есть строка с вашей
    почтой администратора; если это нежелательно, удалите её из index.html перед выкладкой.
  • Скриншоты ранних сборок сняты в тестовом браузере: вместо значков Material Icons стоят
    похожие символы, а графики в сборках 1.0 и V2 пустые. Сами сборки это не меняет.
  • Google Drive: кнопка «Скопировать на Диск» работает только на странице в Claude. На GitHub
    есть ссылки на папки «МайМани» и «iLife_архивы» на Диске; архивы туда загружаются вручную.
