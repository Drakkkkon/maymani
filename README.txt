Мое_сайты 2.4.3 (13 ноября 2026)
================================
Главная страница с программами и их версиями: My Money, iLife (версии 1.2.1–2.6.3), Геометрия Полки, My_topsecret, Oldbook 95, Мое_коровы (альфа-версии 0.0.1–0.0.4, 0.0.8, 0.1.0–0.1.7).
Адрес: https://drakkkkon.github.io/maymani/index.html

Как устроено
- Телефон: страница на всю ширину. Компьютер (от 900 пикселей): колонка шириной в половину окна, по центру.
- У каждой версии одна карточка: номер, дата, журнал изменений (первые пункты сразу, остальное по кнопке «Ещё»), скриншоты и кнопка «Скачать».
- Внизу главной страницы блок «Мои сайты»: иконка, ссылка и одна фраза о сайте.

Где лежат архивы
- ТОЛЬКО на Google Диске, в папке «МайМани». На GitHub архивов нет (.gitignore отсекает *.zip, archives/, *.jks, *.keystore).
- В 2.4.0: страница iLife пополнилась версиями 2.1.0–2.6.0 (архивы 2.1.0–2.4.0 собраны из истории репозитория ilife и положены на Диск), исправлено вылезание карточки версии за край экрана, когда у версии три и больше скриншотов.
- Новая версия любого сайта: положите zip в папку «МайМани» на Диске под именем с номером версии (например iLife_v1.10.0.zip), добавьте запись в js/data.js, загрузите на GitHub только сайт.

Подключение Google Диска
- Кнопка «Подключить Google Диск» открывает вход Google (проект Google Cloud «МайМани», Client ID 228310046677-qmpsno422tsi7bdsfd8tmmqqd0749s25.apps.googleusercontent.com). Доступ: только чтение Диска (drive.readonly), чтобы найти и скачать ваши zip.
- После входа страница ищет файлы по имени. Есть файл: кнопка «Скачать» берёт его прямо с Диска. Нет файла: «Нет на Диске» и имя, под которым его надо загрузить.
- Вход действует около часа, потом появится кнопка «Подключить снова».
- Если Google пишет «Доступ заблокирован» или «приложение не проверено»: в Google Cloud откройте Google Auth Platform, раздел «Аудитория» (Audience), добавьте свою почту в «Test users»; в «Доступ к данным» (Data Access) добавьте область .../auth/drive.readonly; в «Библиотеке» включите Google Drive API. Для адреса в «Authorized JavaScript origins» нужен именно https://drakkkkon.github.io без слеша и без /maymani.
- Без входа кнопки тоже работают: там, где известен файл на Диске, это обычная ссылка; для остальных открывается поиск по Диску.

Закрытые файлы
- Шесть Android-версий My Money (1.0, 1.1, 1.2, 2.0, 2.1, 2.12) содержат ключ подписи и пароль. Их карточки скачивают один общий закрытый архив MayMani_PRIVATE_Android_keys.zip с вашего Диска. Не выкладывайте его на GitHub.

Загрузка на GitHub
Через сайт github.com: Add file, Upload files, перетащите содержимое этой папки (вместе с папками css, js, icons, shots), Commit. Включать Pages заново не нужно, если Pages уже работает для репозитория maymani (Settings, Pages, ветка main, папка /root).
