Мое_Сайты 2.18.0 (28 ноября 2026)
================================
Главная страница с программами и их версиями: My Money (с 4.20.0 есть приложение Android), iLife (версии 1.2.1–2.14.0, с 2.11.0 есть приложение Android), Геометрия Полки, My_topsecret, Oldbook 95, Мое_коровы (альфа-версии 0.0.1–0.4.0, с 0.4.0 есть приложение Android), Мое_граббер (сайт 1.0.0–1.4.0, программа для Windows 1.4.0–1.10.0), Мое_наклейки 1.1.0 (сайт заменён на «Мое_граббер»), Мое_город 0.1.0–0.25.0 (альфа), 1.0.0–1.26.0 (бета), Мое_лимиты (программа для Windows 1.1.0–1.2.0), Мое_мемы 0.1.0–0.3.0 (с 0.3.0 есть APK), Мое_лента 1.0.0–1.4.2 (сам сайт — папка rss/), Мое_новеллы 1.0.0 (программа для Windows; архивы в папке novelly/, исходники и релизы — репозиторий Moe_novelly).
Адрес: https://drakkkkon.github.io/maymani/index.html

Как устроено
- Телефон: одна колонка на всю ширину. Планшет и компьютер (от 700 пикселей): две колонки.
- На главной слева (на телефоне сверху) «Мои сайты» со ссылками, справа «Архив программ».
- У каждой версии одна карточка: номер, дата, журнал изменений (первые пункты сразу, остальное по кнопке «Ещё»), скриншоты и кнопка «Скачать».
- Блок «Мои сайты»: иконка, ссылка и одна фраза о сайте.

Где лежат архивы (с 2.6.0)
- На GitHub, в ветке archives этого же репозитория: папки money/, ilife/, polka/, cows/, grabber/, gorod/, limity/, memy/, rss/, other/.
  Ссылка: https://github.com/Drakkkkon/maymani/tree/archives
- Сайт собирается из ветки main, поэтому архивы его не утяжеляют. Кнопка «Скачать» — прямая ссылка на файл, вход в Google не нужен.
- Новая версия любой программы: положите zip в нужную папку ветки archives (имя с номером версии, например iLife_v2.8.0.zip)
  и добавьте запись в js/data.js с полями file и path (например "path": "ilife/iLife_v2.8.0.zip").
- Ограничение GitHub: один файл не больше 100 МБ. Архивы программ для Windows (*_Windows*.zip / .exe) больше — они хранятся через Git LFS (см. .gitattributes в ветке archives); кнопка «Скачать» работает так же.
- Файлы на Google Диске остались на месте как запасная копия; сайт к Диску больше не подключается (вход Google убран).
- В 2.6.0 добавлены версии: My Money 4.12.0–4.14.0, Геометрия Полки 1.5.0–1.12.0, Мое_коровы 0.3.0.

Закрытые файлы
- Шесть Android-версий My Money (1.0, 1.1, 1.2, 2.0, 2.1, 2.12) содержат ключ подписи и пароль. Их карточки ведут на ваш Google Диск, к общему закрытому архиву MayMani_PRIVATE_Android_keys.zip. Его нет на GitHub (репозиторий публичный), выкладывать его туда не нужно.

Автообновление программ (с Мое_граббер 1.8.0)
- updates/grabber.json — описание последней версии программы «Мое_граббер» для Windows: номер, заметки, ссылки на архивы
  (обновление кода Moe_grabber_app_vX.zip и полный архив) с размером и SHA-256. Программа читает его при запуске и раз в 6 часов.
- Новая версия: положить оба архива в ветку archives (grabber/) и обновить updates/grabber.json.
- updates/limity.json — то же для «Мое_лимиты» (с 1.2.0): номер версии, заметки, ссылка на установщик
  Moe_limity_Setup_X.exe в ветке archives (limity/), размер и SHA-256. Программа читает файл через 15 секунд
  после запуска и раз в 6 часов, скачивает установщик, проверяет SHA-256 и ставит его тихо (/S).
- Новая версия «Мое_лимиты»: положить установщик и архивы в ветку archives (limity/) и обновить updates/limity.json.
- updates/memy.json — обновление приложения Android «Мое_мемы» (с 0.3.0): versionCode, version, url (APK в ветке archives, memy/), sha256, notes.

Загрузка на GitHub
Через сайт github.com: Add file, Upload files, перетащите содержимое этой папки (вместе с папками css, js, icons, shots), Commit. Включать Pages заново не нужно, если Pages уже работает для репозитория maymani (Settings, Pages, ветка main, папка /root).
- updates/money.json — обновление приложения Android «My Money» (с 4.20.0): те же поля, что у memy.json; APK в ветке archives, money/.
  Исходники и сборка — репозиторий my-money, папка android-app.

Приложение Android «Мое_Сайты» (с 2.15.0)
- Исходники: android-hub/ (сборка android-hub/build.sh). Готовые APK: ветка archives, папка hub/.
- Обновление: поднять versionCode и versionName в AndroidManifest.xml, положить APK в hub/ и обновить updates/sayty.json.
- Ключ подписи (moe_sayty.jks и пароль) НЕ хранится на GitHub. Без него обновить установленное приложение нельзя.
- Круглая кнопка «Настройки» в js/site.js видна только внутри приложения.

Разделы (с 2.17.0)
- index.html: только ссылки на сайты. apk.html: версии для Android. sites.html: веб-версии. windows.html: остальное.
- Разделы собираются из js/data.js по полю kind. Новая Android-версия: "kind": "apk"; если в path лежит zip,
  положите сам .apk в ветку archives и добавьте поле "apk": {"file","path","size","sha256"}.
- updates/korovy.json — обновление приложения Android «Мое_коровы» (с 0.4.0): те же поля, что у memy.json, и size; APK в ветке archives, cows/.
  Исходники и сборка — репозиторий Moe_korovy, папка android-app. Ключ подписи на GitHub не хранится.
