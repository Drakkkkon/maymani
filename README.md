# Архивы версий для сайта «Мое_сайты»

Эта ветка `archives` хранит zip-архивы всех версий программ. Сайт https://drakkkkon.github.io/maymani/ собирается из ветки `main`, а кнопки «Скачать» ведут сюда.

Папки: `money/` (My Money), `ilife/` (iLife), `polka/` (Геометрия Полки), `cows/` (Мое_коровы), `other/` (прочее).

Закрытый архив с ключами подписи Android (`MayMani_PRIVATE_Android_keys.zip`) сюда не кладётся: он остаётся только на Google Диске.
